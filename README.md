# Karteikasten

Karteikarten zum Lernen für Wirtschaftsinformatik an der HS Bremerhaven:
Programmierung I, Mathe 1 (Diskrete Mathematik) und Graphen & Automaten.

**Website:** https://lucavoss0301.github.io/karteikasten/

- Fächer mit Unterthemen und „Alles gemischt“
- Fortschrittsbalken pro Fach und Thema
- Eigene Karten, auch handgeschrieben
- Konto mit E-Mail und Passwort: Fortschritt auf allen Geräten
- Funktioniert offline und lässt sich auf den Home-Bildschirm legen

## Dateien

| Datei | Inhalt |
|---|---|
| `index.html` | Die App |
| `cards.js` | Alle eingebauten Karten |
| `config.js` | Verbindung zu Supabase (Login & Datenbank) |
| `sw.js` | Offline-Speicher |
| `supabase.sql` | Datenbank-Tabellen und Sicherheitsregeln |
